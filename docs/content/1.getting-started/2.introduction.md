Welcome to **Bugzilla MCP Server**, a Model Context Protocol (MCP) server that enables secure interaction with Bugzilla instances. This server facilitates communication between AI applications and Bugzilla bug tracking systems through a controlled interface.

Source code: [github.com/SanthoshSiddegowda/bugzilla-mcp](https://github.com/SanthoshSiddegowda/bugzilla-mcp). Licensed under [Apache 2.0](https://github.com/SanthoshSiddegowda/bugzilla-mcp/blob/main/LICENSE).

## What is Bugzilla MCP Server?

Bugzilla MCP Server is an MCP server built with [FastMCP](https://gofastmcp.com) that provides a standardized way for AI applications to interact with Bugzilla bug tracking systems. Whether you're using Claude Code, Claude Desktop, Cursor IDE, or Visual Studio Code, this server enables seamless integration with your Bugzilla instance.

## Quick Start

It runs on your machine, so your Bugzilla API key never leaves it:

- **Claude Desktop**: download [bugzilla-mcp.mcpb](https://github.com/SanthoshSiddegowda/bugzilla-mcp/releases/latest/download/bugzilla-mcp.mcpb), double-click it, and fill in your Bugzilla URL and API key.
- **Claude Code**: `claude mcp add bugzilla -e BUGZILLA_URL=… -e BUGZILLA_API_KEY=… -- uvx bugzilla-mcp`
- **Anything else**: `uvx bugzilla-mcp`, or `pip install bugzilla-mcp` (Python 3.12+)

See [Installation](/getting-started/installation) for every client. Just want to look around first? There's a [hosted server](/getting-started/configuration#hosted-server) for trying it out.

## Key Features

The Bugzilla MCP Server provides a comprehensive set of features for bug tracking:

- **Query Bug Information**: Retrieve details about any bug by ID, compact by default
- **Search Bugs**: Quicksearch syntax or structured multi-field filters
- **Manage Comments**: Add public or private comments to bugs, and tag them
- **Update and File Bugs**: Change status, resolution, assignee, CC and more, or file new bugs
- **Attachments**: Read screenshots (as images), logs and patches; attach text or files
- **History and Triage**: Change history, dependencies, duplicate chains, batch analysis
- **Read-only by Default**: Write tools stay hidden until you [turn them on](/getting-started/configuration#read-only-mode)
- **Local First**: Runs on your machine with your API key in an environment variable or Claude Desktop's secure storage
- **Comprehensive Error Handling**: Robust error handling for reliable operation
- **Quicksearch Documentation**: Built-in access to Bugzilla's quicksearch syntax documentation
- **URL Generation**: Get direct links to bugs and your Bugzilla instance

## Available Tools

The server provides 28 MCP tools. See [Usage](/getting-started/usage) for parameters and examples.

- **Read**: `bug_info`, `bug_comments`, `bug_history`, `bug_dependencies`, `duplicate_chain`, `server_url`, `bug_url`
- **Search**: `bugs_quicksearch`, `learn_quicksearch_syntax`, `bugs_advanced_search`
- **Change**: `update_bug`, `create_bug`, `add_comment`, `tag_comment`
- **Attachments**: `bug_attachments`, `get_attachment`, `upload_attachment`, plus `download_attachments` / `download_attachment` (local server only)
- **Batch and triage**: `bugs_info`, `bugs_comments`, `bugs_analysis_context`, `classify_bugs_heuristics`, `analyze_bugs_statistics`
- **Users and products**: `get_user`, `search_users`, `list_products`, `get_product_components`

## Why Use Bugzilla MCP Server?

- **One-click or one-command install**: a Claude Desktop extension, or `uvx bugzilla-mcp` for every other client
- **Your key stays local**: nothing passes through a third-party server
- **Safe by default**: read-only until you enable writes, a dry run for bulk updates, and approval hints on every tool
- **Built for triage**: batch reads, history, duplicate chains, classification, and screenshots the assistant can see
- **Works with any Bugzilla 5.0+**: Mozilla's, your company's, or your own
