## Quick Start (Hosted Server)

The easiest way to get started is to use the hosted production server. No installation or local setup required!

1. **Get your Bugzilla API key** from your Bugzilla instance:
   - Navigate to: `https://your-bugzilla-instance.com/userprefs.cgi?tab=apikey`
   - Generate a new API key if you don't have one

2. **Configure your MCP client** (see [Configuration](/getting-started/configuration) for details):
   - Add the server URL: `https://bugzilla.fastmcp.app/mcp`
   - Add your API key and Bugzilla URL as headers

That's it! You're ready to use the Bugzilla MCP Server.

## Local Development

If you want to run the server locally for development or testing:

::steps
### Prerequisites

- Python 3.12 or higher
- `uv` package manager (recommended) or `pip`

### Install dependencies

Using `uv` (recommended):

```bash [Terminal]
uv sync
```

Or with standard Python:

```bash [Terminal]
pip install .
```

### Run the server

Using `uv`:

```bash [Terminal]
uv run python server.py
```

Or with standard Python:

```bash [Terminal]
python server.py
```

The server will start at `http://127.0.0.1:8000/mcp/`

### Configure your MCP client

For local development, use `http://127.0.0.1:8000/mcp` as the server URL in your MCP client configuration.
::

## Local stdio Server

`server_local.py` runs the server as a process your MCP client starts itself. Credentials come from environment variables (or a `.env` file), so your API key never goes to a hosted server. It is single-user, and it is the only mode where the tools that read or write files on disk (`download_attachment(s)`, `upload_attachment` with `file_path`) are enabled.

```bash [Terminal]
cp .env.example .env   # then set BUGZILLA_URL and BUGZILLA_API_KEY
```

**Claude Code:**

```bash [Terminal]
claude mcp add bugzilla-local --scope user -- uv run --directory /absolute/path/to/bugzilla-mcp python server_local.py
```

**Claude Desktop / Cursor** (`claude_desktop_config.json` or `.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "bugzilla-local": {
      "command": "uv",
      "args": ["run", "--directory", "/absolute/path/to/bugzilla-mcp", "python", "server_local.py"],
      "env": {
        "BUGZILLA_URL": "https://bugzilla.example.com",
        "BUGZILLA_API_KEY": "your-api-key-here"
      }
    }
  }
}
```

## Development Setup

For contributing to the project:

::prose-steps
### Clone the repository

```bash [Terminal]
git clone https://github.com/SanthoshSiddegowda/bugzilla-mcp.git
cd bugzilla-mcp
```

### Install dependencies

`uv` creates the virtual environment for you:

```bash [Terminal]
uv sync --all-extras
```

### Run the tests

```bash [Terminal]
uv run pytest tests
```

### Inspect the server

You can inspect the MCP server to see available tools:

```bash [Terminal]
uv run fastmcp inspect server.py:mcp
```

This will show you all available tools, their parameters, and descriptions.
::
