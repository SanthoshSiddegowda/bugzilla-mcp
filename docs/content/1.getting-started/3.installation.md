## Install (Recommended)

The server runs on your machine, so your Bugzilla API key never leaves it. It starts read-only; see [Read-only Mode](/getting-started/configuration#read-only-mode) to enable write tools.

First, get an API key from your Bugzilla: `https://your-bugzilla-instance.com/userprefs.cgi?tab=apikey`.

### Claude Desktop: one click

1. Download [bugzilla-mcp.mcpb](https://github.com/SanthoshSiddegowda/bugzilla-mcp/releases/latest/download/bugzilla-mcp.mcpb) from the latest release.
2. Double-click it, or install it from **Settings → Extensions**.
3. Enter your Bugzilla URL and API key. Untick **Read-only** only if Claude should update bugs.

No Python or terminal needed.

### Claude Code

Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then:

```bash [Terminal]
claude mcp add bugzilla --scope user -e BUGZILLA_URL=https://bugzilla.example.com -e BUGZILLA_API_KEY=your-api-key -- uvx bugzilla-mcp
```

Add `--allow-writes` after `bugzilla-mcp` to enable write tools.

### Cursor, VS Code and other clients

```json
{
  "mcpServers": {
    "bugzilla": {
      "command": "uvx",
      "args": ["bugzilla-mcp"],
      "env": {
        "BUGZILLA_URL": "https://bugzilla.example.com",
        "BUGZILLA_API_KEY": "your-api-key"
      }
    }
  }
}
```

If the client can't find `uvx`, use the full path from `which uvx`.

### pip

```bash [Terminal]
pip install bugzilla-mcp
bugzilla-mcp --help
```

`bugzilla-mcp --transport http` runs it as a multi-user HTTP server instead, taking credentials from each request's headers.

## Try the Hosted Server

To try it without installing anything, point your client at `https://bugzilla.fastmcp.app/mcp` with your API key and Bugzilla URL as headers (see [Configuration](/getting-started/configuration)). Your key passes through that server, so install locally for real use.

## Run from Source

To run the server from a checkout (for development or testing):

::steps
### Prerequisites

- Python 3.12 or higher
- `uv` package manager (recommended) or `pip`

### Install dependencies

Using `uv` (recommended):

```bash [Terminal]
uv sync
```

Or with standard Python:

```bash [Terminal]
pip install .
```

### Run the server

Using `uv`:

```bash [Terminal]
uv run python server.py
```

Or with standard Python:

```bash [Terminal]
python server.py
```

The server will start at `http://127.0.0.1:8000/mcp/`

### Configure your MCP client

For local development, use `http://127.0.0.1:8000/mcp` as the server URL in your MCP client configuration.
::

## Local stdio Server from a Checkout

`server_local.py` runs the server as a process your MCP client starts itself. Credentials come from environment variables (or a `.env` file), so your API key never goes to a hosted server. It is single-user, and it is the only mode where the tools that read or write files on disk (`download_attachment(s)`, `upload_attachment` with `file_path`) are enabled.

```bash [Terminal]
cp .env.example .env   # then set BUGZILLA_URL and BUGZILLA_API_KEY
```

**Claude Code:**

```bash [Terminal]
claude mcp add bugzilla-local --scope user -- uv run --directory /absolute/path/to/bugzilla-mcp python server_local.py
```

**Claude Desktop / Cursor** (`claude_desktop_config.json` or `.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "bugzilla-local": {
      "command": "uv",
      "args": ["run", "--directory", "/absolute/path/to/bugzilla-mcp", "python", "server_local.py"],
      "env": {
        "BUGZILLA_URL": "https://bugzilla.example.com",
        "BUGZILLA_API_KEY": "your-api-key-here"
      }
    }
  }
}
```

## Development Setup

For contributing to the project:

::prose-steps
### Clone the repository

```bash [Terminal]
git clone https://github.com/SanthoshSiddegowda/bugzilla-mcp.git
cd bugzilla-mcp
```

### Install dependencies

`uv` creates the virtual environment for you:

```bash [Terminal]
uv sync --all-extras
```

### Run the tests

```bash [Terminal]
uv run pytest tests
```

### Inspect the server

You can inspect the MCP server to see available tools:

```bash [Terminal]
uv run fastmcp inspect server.py:mcp
```

This will show you all available tools, their parameters, and descriptions.
::
